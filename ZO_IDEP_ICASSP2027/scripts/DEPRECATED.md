# Deprecated pipeline

`run_experiments.py` and `run_nonlinear_experiment.py` in this folder are an
**early prototype pipeline**. They are kept only for history and must not be
used for paper numbers or figures.

Two reasons:

1. **Weaker certificate.** Their switch test uses
   `R = ||ghat_S|| / m`, `G = max|ghat_Sc| + L R`, `B = min|x_S| - R` with
   conditions `G < lambda`, `B > eta G`. This drops the `eps`, `2LR` and `2R`
   terms, so it is strictly weaker than conditions (c1)--(c3) of Theorem 3.3 in
   the paper. Certificates checked by this code are not covered by the theorem.
2. **Superseded outputs.** `results/` (top level: `regression_summary.csv`,
   `traces.json`, `nonlinear_logistic_raw.csv`) and the figures
   `figures/pipeline.pdf`, `figures/query_efficiency.pdf`,
   `figures/support_identification.pdf` were generated by this pipeline. Its
   `wrong_freeze` field means "frozen support differs from the planted
   support", which is **not** the definition used by the paper's freeze table
   (endpoint differs from Full-ZO-EP). Numbers disagree with the paper (e.g.
   `(256,16)` reports 58,992 queries instead of 59,568).

## Canonical pipeline

Use the `zo_idep/` package instead:

- code: `zo_idep/src/` (its `certificate.py` implements Theorem 3.3 exactly);
- experiments: `zo_idep/experiments/exp00_unit_tests.py`,
  `exp01_sparse_regression.py` (main table), `exp02_mu_sweep.py` (smoothing),
  `exp03_margin_sweep.py` (identification margin), `exp04_certificate_vs_heuristic.py`
  (freeze stress test), `exp05_rate_and_accuracy.py` (post-switch rate),
  `exp06_sparse_phase_retrieval.py`, `exp07_scaling.py` (scaling table);
- outputs: `zo_idep/results/summary/*.json` + `zo_idep/results/raw/*.jsonl`;
- gates: `python3 zo_idep/scripts/validate_results.py` (zero endpoint gap and
  zero shadow mismatch are enforced) and `make check` for the PDF preflight.
